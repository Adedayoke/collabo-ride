# Ops console

## Overview

Internal staff web console. Its static files are served by Caddy on the same origin as the API (so no CORS), and it calls each owning service's `/admin/*` routes through the gateway. Root `AGENTS.md` rules apply.

## Stack

- Vite + React 19 + TanStack Router (file routes in `src/routes/`)
- Planned per spec 0009: TanStack Query (server data) + Zustand (local state), orval clients from `@collabo/contracts`
- oxlint (`.oxlintrc.json`)

## Commands

```bash
pnpm --filter @collabo/console dev        # vite on 5173, proxies /v1 to 8080 and /socket.io to 8086
pnpm --filter @collabo/console build      # tsc -b && vite build
pnpm --filter @collabo/console typecheck
pnpm --filter @collabo/console lint       # oxlint + oxfmt --check
pnpm --filter @collabo/console format     # oxlint --fix + oxfmt
```

## Conventions

- WCAG AA is the baseline for every screen.
- Build time env is `VITE_API_URL` (empty in production, same origin).

## Gotchas

- `src/routeTree.gen.ts` is generated by the TanStack Router plugin; never edit it by hand.
